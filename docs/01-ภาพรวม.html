ภาพรวมโปรเจกต์และปรัชญาการจูน

Level51Tune คือชุดเครื่องมือบรรทัดคำสั่ง (PowerShell) สำหรับปรับแต่งประสิทธิภาพของเครื่อง LEVEL51 — โน้ตบุ๊ก Clevo รุ่น N95TP6 ที่ใส่ซีพียูเดสก์ท็อป (Intel Core i9-9900K), การ์ดจอ NVIDIA GTX 1060, แรม 32 GB และ SSD NVMe Samsung 990 EVO Plus 1 TB ภายใต้ Windows 11 Pro

เป้าหมายไม่ใช่ "ปุ่มวิเศษที่ทำให้เครื่องเร็วขึ้น 50%" แต่คือการทำให้ทุกอย่างที่ Windows, ไดรเวอร์ และฮาร์ดแวร์ทำนั้น สอดคล้องกัน — ไม่มีคอขวดที่เกิดจากการตั้งค่าที่ขัดกันเอง และทุกการเปลี่ยนแปลงสามารถวัดผลและย้อนกลับได้

ในหน้านี้
  1. ปัญหาที่เครื่องลักษณะนี้มักเจอ
  2. หลักการ 4 ข้อของ Level51Tune
  3. สถาปัตยกรรมของโปรแกรม
  4. ระดับความเสี่ยง
  5. สิ่งที่โปรแกรมนี้ *ไม่* ทำ
  6. จะเริ่มยังไง

ปัญหาที่เครื่องลักษณะนี้มักเจอ

เครื่องระดับนี้มีจุดอ่อนเชิงสถาปัตยกรรมที่ tweak ซอฟต์แวร์แก้ได้บางส่วน และแก้ไม่ได้บางส่วน การรู้ว่าอันไหนคืออันไหนคือหัวใจของการจูนทั้งหมด

อาการสาเหตุที่แท้จริงแก้ด้วยซอฟต์แวร์ได้ไหม
เฟรมไทม์กระตุกเป็นช่วง ๆCPU ถูกจำกัดพลังงาน (PL1/PL2) และร้อนเร็วเพราะใช้ซีพียูเดสก์ท็อปในตัวเครื่องบางได้บางส่วน (ลดงานพื้นหลัง, เปิด cooling policy active) — ที่เหลือต้องแก้ที่ BIOS/ระบบระบายความร้อน
เกมใช้ Intel UHD 630 แทน GTX 1060Optimus เลือก GPU ผิดให้โปรแกรมที่ไม่ได้ลงทะเบียนได้ (GPU preference + per-app registry)
เปิดโปรแกรมครั้งแรกช้าSysMain/Prefetcher ถูกปิด หรือดิสก์ถูกจำกัดด้วย ASPMได้ (ปรับ power scheme, เปิด/ปิด prefetch ตามงาน)
ดีเลย์ในการคลิก/ยิงtimer coalescing, Nagle, MMCSS priority ต่ำ, core parkingได้ (นี่คือกลุ่ม tweak หลักของโปรไฟล์ gaming)
เครื่องร้อนและพัดลมดังตอน idleC-state ถูกปิดค้าง, boost aggressive, fan curve จาก BIOSได้บางส่วน — และบาง tweak ของโปรแกรมนี้คือสาเหตุ (ต้องรู้จักย้อนกลับ)
แบตหมดเร็วstate ขั้นต่ำสูง, boost เต็ม, ASPM ปิดได้ (โปรไฟล์ battery)

หลักการ 4 ข้อของ Level51Tune

1. วัดก่อน วัดหลัง — ทุกโปรไฟล์มี bench คู่กันเสมอ ตัวเลข CPU/RAM/Disk ถูกเก็บใน benchmarks/history.jsonl และเทียบได้ด้วย compare ไม่มีการอ้างว่า "เร็วขึ้น" โดยไม่มีตัวเลขรองรับ

2. สำรองก่อนทุกครั้ง — apply จะสร้างไฟล์ backups/<เวลา>_apply-<โปรไฟล์>.json ที่บรรจุค่าก่อนหน้าของทุก tweak (ค่า power index, ค่า registry เดิม, สถานะบริการ, power scheme ที่ใช้อยู่) ก่อนที่จะแก้อะไรหนึ่งอย่าง

3. ย้อนกลับได้หนึ่งคำสั่ง — restore อ่านไฟล์ backup แล้วคืนค่าทุกอย่างตามลำดับย้อนกลับ ลบ power scheme ที่สร้างขึ้น และสลับกลับไป scheme เดิม

4. แยก scheme ไม่แตะของเดิม — โปรแกรมไม่แก้ power plan "Balanced" ของคุณ แต่จะ powercfg -duplicate ออกมาเป็น scheme ใหม่ชื่อ LEVEL51-TUNE <โปรไฟล์> แล้วสลับไปใช้ scheme นั้น ทำให้แผนเดิมยังสมบูรณ์แบบ 100%

สถาปัตยกรรมของโปรแกรม

Level51Tune.ps1              CLI entry (parsing, help, exit codes)
└── src/
    ├── Level51Tune.psm1     engine: ตรวจฮาร์ดแวร์, backup, apply, restore, audit, docs
    ├── Catalog.ps1          ข้อมูล tweaks ทั้งหมด (declarative, ไม่มี logic)
    ├── Markdown.ps1         markdown → HTML renderer (ไม่ต้องพึ่งโมดูลภายนอก)
    └── Bench.ps1            micro-benchmark + history + compare
docs/                        เอกสาร md (ต้นฉบับ) และ html (สร้างจาก md)
tools/Build-Docs.ps1         สร้าง html จาก md
tests/Test-Level51Tune.ps1   ชุดทดสอบที่ไม่ต้องใช้สิทธิ์ admin

แนวคิดสำคัญ: tweak คือข้อมูล ไม่ใช่โค้ด แต่ละรายการใน Catalog.ps1 ประกาศว่าตัวเองเป็นประเภทไหน (Power, Registry, Service, Script) ต้องใช้สิทธิ์ admin ไหม เสี่ยงระดับไหน อยู่โปรไฟล์ใด แล้ว engine จะรู้วิธี backup/apply/revert ให้เอง การเพิ่ม tweak ใหม่จึงทำได้โดยไม่ต้องแก้ engine

ระดับความเสี่ยง

ระดับความหมายต้องเปิดเองไหม
Lowคืนค่าเดิมของ Windows ได้ทันที ไม่กระทบความเสถียรไม่ (อยู่ในโปรไฟล์เลย)
Mediumเปลี่ยนพฤติกรรมที่ผู้ใช้รู้สึกได้ (เช่น ปิด SysMain, Win32PrioritySeparation) หรือกินไฟขึ้นชัดไม่ แต่ควรอ่านหมายเหตุก่อน
Highอาจทำให้เครื่องไม่เสถียร/ร้อนมาก/ต้อง reboot และแก้คืนยากกว่าใช่ ต้องใส่ -Include high

tweaks ระดับ High ทั้งหมดของโปรเจกต์นี้มี 3 รายการ: power.cpu.idle-disable (ปิด C-state), gpu.nvlddmkm-pstate (ปิด P-State ของไดรเวอร์ NVIDIA) และ win.bcd-dynamictick / win.bcd-platformclock (แก้ boot configuration) — ทั้งหมดอยู่ในโปรไฟล์ max เท่านั้นและจะถูกข้ามถ้าไม่ระบุ -Include high

สิ่งที่โปรแกรมนี้ *ไม่* ทำ

ต้องพูดให้ชัดเพื่อไม่ให้คาดหวังเกิน:

  • ไม่ undervolt CPU/GPU — การ undervolt i9-9900K ต้องใช้ Intel XTU หรือ ThrottleStop และต้องทดสอบเสถียรภาพทีละขั้น (ดู เชิงลึก: BIOS และฮาร์ดแวร์)
  • ไม่แฟลช BIOS หรือแก้ fan curve — เป็นงานระดับ firmware ต้องทำใน BIOS setup ตอนบูต
  • ไม่ติดตั้งไดรเวอร์หรือ DDU — โปรแกรมตรวจเวอร์ชันให้ แต่การติดตั้งเป็นหน้าที่คุณ
  • ไม่ปิด Windows Update / Defender แบบถาวร — ไม่ใช่การจูนประสิทธิภาพ แต่คือการลดความปลอดภัย
  • ไม่ overclock — เครื่องนี้มี margin น้อยมากจากระบบระบายความร้อน

จะเริ่มยังไง

  1. อ่าน ติดตั้งและเริ่มต้นใช้งาน แล้วรัน status + bench -Label before
  2. เลือกโปรไฟล์จาก โปรไฟล์และสิ่งที่แต่ละโปรไฟล์เปลี่ยน — เริ่มที่ performance หรือ gaming
  3. ทดลองด้วย -DryRun ก่อน แล้วค่อย apply จริง
  4. วัดซ้ำ bench -Label after และ compare
  5. ถ้าไม่ชอบอะไรก็ restore — ไม่มีอะไรค้างคา

คำเตือนที่ต้องย้ำ: โปรไฟล์ max ตั้งใจให้เครื่องร้อนและกินไฟมากขึ้นอย่างมีนัยสำคัญ บน N95TP6 ที่ใช้ซีพียู 95W ในตัวเครื่องบาง อุณหภูมิอาจแตะจุด throttling ภายในไม่กี่นาที ซึ่งทำให้ *แย่ลง* กว่าเดิมถ้าระบบระบายความร้อนไม่พร้อม ใช้เฉพาะงาน burst สั้น ๆ และตรวจอุณหภูมิด้วย status ทุกครั้ง
