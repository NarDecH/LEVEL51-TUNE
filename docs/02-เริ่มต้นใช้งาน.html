ภาพรวมโปรเจกต์และปรัชญาการจูน ติดตั้งและเริ่มต้นใช้งาน คู่มือคำสั่ง CLI โปรไฟล์และสิ่งที่แต่ละโปรไฟล์เปลี่ยน จูน CPU เชิงลึก (Core i9-9900K) จูน GPU (GTX 1060 + UHD 630) พลังงาน แบตเตอรี่ และความร้อน RAM และ Storage เครือข่ายและ latency Windows, services และ debloat เชิงลึก: BIOS, ฮาร์ดแวร์ และการวัดผล ความปลอดภัย การสำรอง และการย้อนกลับ ผลตรวจเครื่อง LEVEL51 (ค่าจริง) แก้ปัญหาและคำถามที่พบบ่อย

สิ่งที่ต้องมี

รายการข้อกำหนดหมายเหตุ
ระบบปฏิบัติการWindows 10 21H2+ หรือ Windows 11ตรวจด้วย winver
PowerShell5.1 (มีมาในเครื่อง) หรือ 7.xทั้งสองเวอร์ชันรองรับ
สิทธิ์Administrator สำหรับ apply / restore / backupstatus, audit, bench, docs ไม่ต้องใช้
ดิสก์ว่าง~500 MBสำหรับ benchmark ชั่วคราว 256 MB + backups
โมดูลภายนอกไม่ต้องมีไม่ต้องติดตั้ง Pester/PSFramework ใด ๆ

ขั้นตอนที่ 1: ได้ไฟล์โปรเจกต์

ถ้าโคลนจาก GitHub:

cd C:\_Project
git clone https://github.com/NarDecH/LEVEL51-TUNE.git
cd LEVEL51-TUNE

ถ้ามีโฟลเดอร์อยู่แล้วให้เข้าไปที่รากของโปรเจกต์ (ที่มีไฟล์ Level51Tune.ps1)

ขั้นตอนที่ 2: ปลดล็อกสคริปต์ (ถ้าจำเป็น)

Windows อาจบล็อกสคริปต์ที่ดาวน์โหลดมา ถ้ารันแล้วขึ้น "cannot be loaded because running scripts is disabled" ให้เลือกวิธีใดวิธีหนึ่ง:

# วิธีที่ปลอดภัยที่สุด: ปลดล็อกเฉพาะไฟล์ที่ดาวน์โหลดมา
Get-ChildItem -Recurse -Include *.ps1,*.psm1 | Unblock-File

# หรืออนุญาตเฉพาะ PowerShell ที่เปิดอยู่ในขณะนี้ (ไม่เปลี่ยนค่าระบบถาวร)
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

ไม่แนะนำ Set-ExecutionPolicy Unrestricted -Scope LocalMachine — เปลี่ยนนโยบายทั้งเครื่องโดยไม่จำเป็น

ขั้นตอนที่ 3: ตรวจสถานะก่อนแตะอะไร

.\Level51Tune.ps1 status

ขั้นตอนที่ 4: วัดผลก่อน (สำคัญที่สุด)

.\Level51Tune.ps1 bench -Label before

ใช้เวลาราว 15-25 วินาที (CPU 2 รอบ × 3 วินาที, RAM copy, ดิสก์เขียน/อ่าน 256 MB) ผลจะถูกเพิ่มใน benchmarks/history.jsonl

  CPU 1 thread   :        447 MB/s
  CPU 16 threads :      2,964 MB/s  (efficiency 83% ของ 8 physical cores)
  Memory copy    :      4,949 MB/s
  Disk write     :      1,213 MB/s
  Disk read      :      4,208 MB/s  (อาจได้จาก cache)

CPU ... MB/s คือ throughput ของ SHA-256 บนบัฟเฟอร์ 4 MB — เลือกงานนี้เพราะงานหนักอยู่ใน native code ผลจึงสะท้อนความเร็วซีพียูจริง ไม่ใช่ความเร็วของ PowerShell เอง

efficiency % คือ (throughput ทุก thread ÷ throughput 1 thread ÷ จำนวน physical cores) × 100 — ใช้ physical cores เพราะ Hyper-Threading ไม่เพิ่ม throughput เต็ม 100% ค่า 100% = สเกลได้สมบูรณ์ เครื่องนี้ได้ ~83% ซึ่งปกติ; ถ้าต่ำกว่า ~65% มักหมายถึงเครื่องถูกจำกัดพลังงานหรือความร้อน

ตัวเลขเหล่านี้ไม่ใช่คะแนนมาตรฐานสากล (ไม่เทียบกับ Cinebench ได้) แต่มีประโยชน์มากในการเทียบ เครื่องเดียวกัน ก่อนกับหลัง

ขั้นตอนที่ 5: ทดลองก่อนด้วย DryRun

DryRun จะเดินทุกขั้นตอนเหมือนจริง แต่ไม่สั่งอะไรที่เปลี่ยนแปลงระบบ — ปลอดภัยแม้ไม่มีสิทธิ์ admin

.\Level51Tune.ps1 apply -Profile gaming -DryRun

จะเห็นรายการทั้งหมดพร้อมคำสั่งที่จะรัน เช่น

  [*] โปรไฟล์: เกมมิ่ง (latency ต่ำ) (gaming)
  1/24 power.cpu.min50                                  OK
      powercfg setacvalueindex SCHEME_CURRENT SUB_PROCESSOR PROCTHROTTLEMIN 50 + ...
  2/24 gpu.hags                                         OK
      set HKLM:\SYSTEM\CurrentControlSet\Control\GraphicsDrivers\HwSchMode = 2 (DWord)

ขั้นตอนที่ 6: Apply จริง

# เปิด PowerShell แบบ Administrator ก่อน แล้วรัน:
.\Level51Tune.ps1 apply -Profile gaming

หรือให้โปรแกรมขอ UAC เอง:

.\Level51Tune.ps1 apply -Profile gaming -Elevate

ลำดับที่โปรแกรมทำ:

  1. ตรวจสิทธิ์ admin
  2. อ่านฮาร์ดแวร์ + power scheme ปัจจุบัน
  3. powercfg -duplicate scheme ปัจจุบัน → scheme ใหม่ LEVEL51-TUNE gaming
  4. บันทึก snapshot ลง backups/
  5. apply ทีละ tweak พร้อมรายงาน OK / WARN / SKIP / FAIL
  6. powercfg -setactive scheme ใหม่
  7. เขียน state/last.json (จำว่าใช้อะไรอยู่ เพื่อไม่สร้าง scheme ซ้ำซ้อน)

ตัวอย่างท้ายการทำงาน:

  [+] เสร็จสิ้น: 23 สำเร็จ, 0 มีปัญหา, 1 ข้าม
  [!] ข้าม tweaks เสี่ยงสูง 1 รายการ (ใช้ -Include high เพื่อเปิด): power.cpu.idle-disable
  [i] ย้อนกลับด้วย: .\Level51Tune.ps1 restore -BackupPath 'C:\_Project\LEVEL51-TUNE\backups\20261112-153012_apply-gaming.json'
  [!] มี tweaks ที่ต้อง restart จึงจะมีผลเต็มที่

ขั้นตอนที่ 7: วัดผลหลัง และเปรียบเทียบ

.\Level51Tune.ps1 bench -Label after
.\Level51Tune.ps1 compare
  before  ->  after
   CPU 1 thread (MB/s)         448.0 ->    462.0      3.1%
   CPU all threads (MB/s)     2666.0 ->   2790.0      4.7%
   Memory (MB/s)              4949.0 ->   5010.0      1.2%
   Disk write (MB/s)          1213.0 ->   1240.0      2.2%
   Disk read (MB/s)           4208.0 ->   4290.0      1.9%

อ่านตัวเลขให้ถูก: micro-benchmark มี noise ±3-5% การต่างต่ำกว่านั้นคือ "ไม่ต่าง" โปรไฟล์ tuning ส่วนใหญ่ไม่ได้เพิ่ม throughput ดิบ แต่ลด latency และ jitter ซึ่ง bench วัดไม่ได้ตรง ๆ (ต้องใช้ LatencyMon หรือ frametime graph ของเกม)

โครงสร้างไฟล์ที่โปรแกรมสร้าง

โฟลเดอร์เนื้อหาอยู่ใน git ไหม
backups/snapshot JSON ก่อน apply ทุกครั้งไม่ (gitignore)
logs/log รายวัน l51-YYYYMMDD.logไม่
benchmarks/history.jsonl ผลวัดทุกครั้งไม่
state/last.json สถานะ apply ล่าสุดไม่
reports/รายงาน markdown จาก reportไม่

คำสั่งที่ใช้บ่อย

.\Level51Tune.ps1 status                  # ดูสถานะ
.\Level51Tune.ps1 profiles                # ดูโปรไฟล์ทั้งหมด
.\Level51Tune.ps1 audit -Profile gaming   # อะไรถูกปรับแล้วบ้าง
.\Level51Tune.ps1 list -Category GPU      # ดู tweaks หมวด GPU
.\Level51Tune.ps1 apply -Profile performance
.\Level51Tune.ps1 restore                 # ย้อนกลับจาก backup ล่าสุด
.\Level51Tune.ps1 docs -Open              # เปิดเอกสาร HTML

ถ้าติดปัญหา

อาการวิธีแก้
ไม่รู้จักคำสั่งใช้ .\Level51Tune.ps1 help
ต้องใช้สิทธิ์ Administratorเปิด PowerShell แบบ Run as administrator หรือเพิ่ม -Elevate
สคริปต์ถูกบล็อกUnblock-File ตามขั้นตอนที่ 2
ตัวอักษรไทยใน console เพี้ยนใช้ Windows Terminal หรือรัน chcp 65001 ก่อน (เฉพาะ PowerShell 5.1)
powercfg ปฏิเสธค่า (WARN)ค่านั้นถูกซ่อนอยู่ — apply โปรไฟล์ที่มี win.unhide-power-settings ก่อน
