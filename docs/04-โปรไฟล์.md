# โปรไฟล์และสิ่งที่แต่ละโปรไฟล์เปลี่ยน

โปรไฟล์คือ "ชุด tweaks ที่เลือกไว้แล้ว" การเลือกโปรไฟล์ไม่ได้แปลว่าเครื่องจะเร็วขึ้นเสมอ — มันแปลว่าเครื่องจะถูกปรับให้เหมาะกับงานชนิดหนึ่ง โดยแลกกับอย่างอื่น

## ภาพรวม 5 โปรไฟล์

| โปรไฟล์ | ปรัชญา | จำนวน tweaks | เหมาะกับ | แลกกับ |
|---|---|---|---|---|
| `balanced` | เปิดของที่ได้ผลและปลอดภัยที่สุด | 6 | ใช้งานทั่วไป, เครื่องทำงาน | แทบไม่มี |
| `performance` | ลด latency พื้นฐานโดยไม่ทำเครื่องร้อนเกิน | 18 | งานประจำวัน, เขียนโค้ด, เรนเดอร์สั้น | กินไฟมากขึ้นเล็กน้อย |
| `gaming` | latency ต่ำสุดสำหรับเกม/VR | 24 | เล่นเกม, งานอินเทอร์แอกทีฟ | กินไฟ, ความร้อน, ปิดฟีเจอร์ Windows บางอย่าง |
| `max` | ดึงทุกอย่างที่ทำได้ (รวม High risk) | 32 | benchmark, burst workload | ร้อนมาก, กินไฟมาก, ฟีเจอร์บางอย่างหาย |
| `battery` | ประหยัดไฟเมื่อไม่ได้ต่อสาย | 7 | พาออกนอกบ้าน | ประสิทธิภาพลดลงชัด |

จำนวน tweaks นับจากแค็ตตาล็อกจริง (`list` จะแสดงให้ตรวจสอบได้) และโปรไฟล์หนึ่ง ๆ อาจได้ tweak ไม่ครบถ้าการตั้งค่านั้นถูกซ่อนหรือไม่มีอยู่ในเครื่อง

## balanced — baseline ที่ปลอดภัย

สิ่งที่ทำ:

| Tweak | ผล |
|---|---|
| `gpu.hags` | เปิด Hardware-Accelerated GPU Scheduling |
| `gpu.gamedvr-off` | ปิด GameDVR (อัดหน้าจอเบื้องหลัง) |
| `win.gamemode-on` | เปิด Game Mode |
| `net.throttling-off` | ปิด NetworkThrottlingIndex |
| `disk.last-access-off` | ยืนยันว่าปิด NTFS last access (ปกติ Win11 ปิดอยู่แล้ว) |

เมื่อใช้: เป็นจุดเริ่มต้นสำหรับคนที่ไม่เคยจูน ปลอดภัยพอที่จะเปิดค้างไว้ตลอด และใช้เป็น "กลุ่มควบคุม" เวลาเปรียบเทียบผล

## performance — ใช้งานประจำวัน

เพิ่มจาก balanced:

| Tweak | ค่า | ผลที่คาดหวัง |
|---|---|---|
| `power.cpu.min50` | min state 50% (AC) | ลดการสลับ P-state ถี่ ลด jitter |
| `power.cpu.max100` | max state 100% (AC+DC) | ปลดล็อกความเร็วเต็มตอนใช้แบต |
| `power.cpu.boost-enabled` | boost = Enabled | ให้ Turbo ทำงานปกติ |
| `power.cpu.cooling-active` | cooling = Active | พัดลมนำการลด clock (ดีต่อประสิทธิภาพ) |
| `power.cpu.epp-performance` | EPP 25 | CPU เอนไปทางความเร็ว |
| `power.cpu.thresholds` | increase threshold 30 | ขึ้น clock เร็วขึ้นเมื่อมีงาน |
| `power.pcie.aspm-off` | ASPM off (AC) | NVMe/GPU ตื่นเร็วขึ้น |
| `power.disk.timeout-never` | ดิสก์ไม่ sleep | ไม่มีอาการค้าง 1-2 วินาที |
| `power.video.timeout-20m` | จอดับ 20 นาที | ไม่จอดับกลางงานยาว |
| `power.sleep.never-ac` | ไม่ sleep (AC) | งานยาวไม่ถูกตัด |
| `net.tcp-global` | autotuning normal, RSS on | throughput เครือข่ายเสถียร |
| `mem.priority-separation` | 38 | foreground ได้ CPU มากกว่า |
| `disk.defrag-task-off` | ปิด defrag ตามกำหนด | ไม่มี IO พื้นหลังระหว่างงาน |
| `win.unhide-power-settings` | ปลดซ่อนค่า power ขั้นสูง | ปรับเองใน Control Panel ได้ |

**ผลข้างเคียงที่ต้องรู้**: min state 50% ทำให้ idle power สูงขึ้นเล็กน้อย (พัดลมอาจดังขึ้นตอนพัก) และ `mem.priority-separation` ต้อง reboot

## gaming — latency ต่ำ

เพิ่มจาก performance:

| Tweak | ค่า | ผล |
|---|---|---|
| `power.cpu.coreparking-off` | core parking ปิด (AC 100%) | ไม่มี wake latency ของคอร์ |
| `power.usb.suspend-off` | ปิด USB selective suspend | เมาส์/คีย์บอร์ด/capture card ตอบสนองนิ่ง |
| `gpu.gamedvr-policy` | ปิด GameDVR ทั้งเครื่อง | ไม่มี encoder แย่ง GPU |
| `gpu.fullscreen-opt-off` | ปิด fullscreen optimization | exclusive fullscreen, input lag ต่ำลง |
| `gpu.fullscreen-opt-honor` | เคารพการตั้งต่อโปรแกรม | — |
| `gpu.prefer-dgpu-global` | default GPU = GTX 1060 | เกมไม่ไปใช้ UHD 630 |
| `gpu.nvidia-telemetry-off` | ปิด NvTelemetryContainer | ไม่มี background service ของไดรเวอร์ |
| `net.mmcss-responsiveness` | 10 | สำรอง CPU ให้ multimedia น้อยลง |
| `net.mmcss-games` | GPU Priority 8, Priority 6, High | thread ของเกมได้คิวก่อน |
| `net.nagle-off` | TcpAckFrequency=1, TCPNoDelay=1 | ลดดีเลย์แพ็กเก็ตเล็ก |
| `win.mouse-accel-off` | ปิด mouse acceleration | การเล็งตรงกับมือ |
| `win.mouse-thresholds` | threshold = 0 | ทำงานคู่กับข้างบน |
| `win.keyboard-delay` | ดีเลย์สั้นสุด | กดรัวได้ไว |

**เครื่องนี้เหมาะกับ gaming ไหม?** GTX 1060 6 GB ยังเล่นเกม 1080p ยุค 2016-2020 ได้ดี แต่ i9-9900K ในตัวเครื่อง N95TP6 จะชนเพดานความร้อนเร็ว การปิด core parking ทำให้ร้อนเร็วกว่าปกติ ถ้าเฟรมกระตุกหลังเล่น 10 นาที ให้ดู `status` ว่าอุณหภูมิเท่าไร และพิจารณาใช้ `performance` แทน

## max — สูงสุด (ใช้อย่างระวัง)

เพิ่มจาก gaming:

| Tweak | ค่า | ผล / ความเสี่ยง |
|---|---|---|
| `power.cpu.min100` | min state 100% | latency ต่ำสุด, ร้อนตลอดเวลา |
| `power.cpu.boost-aggressive` | boost = Aggressive | กระโดด clock ทันที, กินไฟพุ่ง |
| `power.cpu.epp-max` | EPP 0 | เลือกความถี่สูงสุดเสมอ |
| `power.throttling-off` | ปิด EcoQoS | งานพื้นหลังไม่ถูกหน่วง |
| `power.hibernate-off` | ปิด hibernate + fast startup | คืนพื้นที่ ~32 GB, cold boot จริง |
| `mem.large-system-cache` | LargeSystemCache 1 | file cache มากขึ้น |
| `mem.ntfs-memory-usage` | NtfsMemoryUsage 2 | metadata cache มากขึ้น |
| `mem.sysmain-off` | ปิด SysMain | ลด IO พื้นหลัง |
| `mem.prefetch-off` | ปิด Prefetcher | ลด IO, โปรแกรมเปิดช้าลงเล็กน้อย |
| `disk.indexing-off` | ปิด Windows Search | ลด IO, ค้นหาช้าลงมาก |
| `disk.8dot3-off` | ปิดชื่อไฟล์ 8.3 | metadata น้อยลง |
| `win.visualfx-performance` | visual effects = performance | ปิด animation |
| `win.transparency-off` | ปิด transparency | compositor เบาลง |
| `win.background-apps-off` | ปิดแอปพื้นหลัง | แอป Store ไม่ทำงานเบื้องหลัง |
| `win.services-diagtrack` | ปิด DiagTrack | ลด telemetry |
| `win.services-dmwappush` | ปิด dmwappushservice | — |
| `win.services-mapsbroker` | ปิด MapsBroker | — |
| `power.cpu.idle-disable` (High) | ปิด C-state | latency ต่ำสุด, +20-40W idle |
| `gpu.nvlddmkm-pstate` (High) | ปิด dynamic P-State | clock นิ่ง, GPU ร้อนตลอด |
| `win.bcd-dynamictick` (High) | disabledynamictick | timer jitter ต่ำลง |
| `win.bcd-platformclock` (High) | useplatformclock false | บังคับ TSC |

> **คำเตือนจริงจัง**: `max` บนเครื่องนี้ไม่ใช่โปรไฟล์สำหรับเล่นเกมเป็นชั่วโมง ๆ การรวม min state 100% + boost aggressive + C-state off + GPU P-State off จะทำให้ทั้ง CPU (95W TDP) และ GPU ปล่อยความร้อนพร้อมกัน ในตัวเครื่องที่ระบายความร้อนด้วยฮีตไปป์ 2-3 ท่อ อุณหภูมิจะชน 95-100°C ภายใน 5-10 นาที แล้ว throttling จะทำให้ประสิทธิภาพ **ต่ำกว่า** โปรไฟล์ gaming ใช้เฉพาะ benchmark สั้น ๆ

## battery — ประหยัดไฟ

ทุก tweak ในโปรไฟล์นี้แตะเฉพาะฝั่ง **DC** (ตอนใช้แบต) ไม่แตะ AC:

| Tweak | ค่า DC | ผล |
|---|---|---|
| `battery.cpu.min5` | min 5% | downclock ลึกสุด |
| `battery.cpu.max70` | max 70% | ตัด boost |
| `battery.cpu.boost-efficient` | boost = Efficient Enabled | boost เฉพาะเมื่อคุ้ม |
| `battery.cooling-passive` | cooling = Passive | ลด clock ก่อนเร่งพัดลม (เงียบ) |
| `battery.pcie-aspm-max` | ASPM max savings | NVMe/GPU ประหยัดสุด |
| `battery.video-timeout-5m` | จอดับ 5 นาที | จอคือตัวกินไฟอันดับหนึ่ง |
| `battery.lid-sleep` | ปิดฝา = sleep | — |

**ข้อควรระวัง**: i9-9900K ไม่ใช่ซีพียูประหยัดไฟ ถึงจะจำกัดที่ 70% ก็ยังกินไฟมากกว่า U-series หลายเท่า โปรไฟล์นี้ช่วยได้จริงแต่ไม่ได้ทำให้เป็น ultrabook — คาดว่าได้เพิ่มขึ้น 20-40% ของเวลาใช้งาน แล้วแต่ภาระงาน

## การเลือกโปรไฟล์

```
ต้องการความเสถียรสูงสุด ──────────────► balanced
ใช้งานทั่วไป/ทำงาน ────────────────────► performance
เล่นเกมเป็นหลัก ───────────────────────► gaming
benchmark / burst สั้น ๆ ──────────────► max (+ -Include high ถ้าจำเป็น)
ออกไปข้างนอก ใช้แบต ─────────────────► battery
```

**เปลี่ยนไปมาได้ตลอด** เพราะแต่ละครั้งจะสร้าง scheme ใหม่และ backup เก็บค่าเดิมไว้ ทดลอง `performance` หนึ่งสัปดาห์ แล้วค่อยขยับไป `gaming` จะปลอดภัยกว่ากระโดดไป `max` เลย

> **สำคัญ: apply ไม่ใช่การเลเยอร์** — ทุกครั้งที่ apply โปรแกรมจะ duplicate จาก scheme **ต้นฉบับ** (scheme ที่คุณใช้ก่อน apply ครั้งแรก) แล้วใส่เฉพาะ tweaks ของโปรไฟล์นั้น
>
> ตัวอย่าง: apply `performance` แล้ว apply `battery` ต่อ → ผลลัพธ์คือ *Balanced + battery* (ค่าของ performance ทั้งหมดหายไป)
>
> ถ้าต้องการผลรวมของสองโปรไฟล์ ให้ใช้โปรไฟล์ที่ครอบคลุมอยู่แล้ว (`gaming` มี tweaks ของ `performance` รวมอยู่, `max` มีของ `gaming`) หรือปรับค่าที่เหลือด้วยมือใน Control Panel

## ตรวจสอบว่าโปรไฟล์ทำงานจริง

```powershell
.\Level51Tune.ps1 audit -Profile gaming
```

ถ้าคอลัมน์ `Applied` เป็น `no` ทั้งที่เพิ่ง apply แสดงว่า:

- tweak นั้นเป็นประเภท Script ที่ไม่มี detect (แสดง `?`) — ปกติ
- ค่า power ถูกซ่อนและถูกปฏิเสธ (ดู `WARN` ตอน apply) — ให้ apply โปรไฟล์ที่มี `win.unhide-power-settings` ก่อน
- Windows Update หรือโปรแกรมอื่น (เช่น Armoury Crate, ThrottleStop, GeForce Experience) เขียนทับค่า — ต้องปิดตัวจัดการพลังงานของ OEM

## การปรับแต่งเพิ่มหลัง apply

บางอย่างควรทำด้วยมือหลัง apply เพื่อผลที่ดีกว่า:

- ตั้ง per-app GPU preference ใน Settings → System → Display → Graphics สำหรับเกมที่ยังไปใช้ iGPU
- สร้าง fan curve ใน BIOS (ดู [เชิงลึก: BIOS และฮาร์ดแวร์](11-เชิงลึก-BIOS-และฮาร์ดแวร์.md))
- ตั้ง NVIDIA Control Panel: Power management = Prefer maximum performance (เฉพาะตอนเล่นเกม), Low latency mode = On
- ปิด startup apps ที่ไม่จำเป็นใน Task Manager
